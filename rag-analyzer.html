RAG Simulator

Understand how Retrieval Augmented Generation works visually — from chunking documents to vector embeddings, similarity search, retrieval, and finally LLM generation.

STEP 1
Input Knowledge
Paste any knowledge source below. Imagine this as PDFs, books, company docs, APIs, etc.
STEP 2
Chunking
Large documents are broken into smaller chunks with overlap.
STEP 3
Vector Embeddings
Each chunk gets converted into numerical vector embeddings.
STEP 4
Similarity Search
User query is converted into vectors and matched against the vector database.
STEP 5
User Query + LLM Generation
Ask a question. The simulator retrieves the most relevant chunks and sends them to the LLM.
